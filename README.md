# USFOGA Event Budget Request

USFOGA event budget form with projected revenue, event expenses, travel, deposit details, and membership goals.

## Files

- `index.html`: form, validation, calculations, and submission handling.
- `branding.css`: USFOGA navy, red, and white styling.
- `usfoga-logo-transparent.png`: logo with a transparent background.
- `config.js`: safe default configuration, with live submission disabled.

## Hosting status

This repository is private. GitHub Pages currently requires a plan upgrade for this repository. No website has been deployed from this repository yet.

The live local form and its tested Power Automate flow remain separate and operational. No submitted budgets, workbook data, or signed Power Automate trigger URL are stored here.

Before deployment, configure the submission service and verify an end-to-end test from the final hosted address.
