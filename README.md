# USFOGA Event Budget Request

USFOGA event budget form with projected revenue, event expenses, travel, deposit details, and membership goals.

## Website

https://ryanfia.github.io/usfoga-event-budget/

GitHub Pages publishes the root of the main branch over HTTPS. This repository and the website are public. Live submission availability is controlled by config.js. Document uploads remain disabled until their SharePoint storage steps are implemented.

## Files

- index.html: form, validation, calculations, and submission handling.
- branding.css: USFOGA navy, red, and white styling.
- usfoga-logo-transparent.png: logo with a transparent background.
- config.js: submission service configuration and feature flags.

No submitted budgets or workbook data belong in this repository. Browser-served configuration is visible to site visitors. Changes to the submission service should be tested from the hosted website before use.
